# 우더기네 핵심 청약 카드

사용자 확정 기준: 서울·경기, **단지 전체** 500세대 이상, **이번 모집 전용 84㎡** 분양가 10억원 초과. 이번 모집 세대수 하한 없음. 공고 API TOT_SUPLY_HSHLDCO는 이번 모집 물량이며 단지 총세대수로 사용하지 않는다. 500세대 미만인 별개 단지를 합산하지 않는다.

공식 총 세대수, 최신 공고의 자격과 동·호수별 가격표, 일정·주의사항을 검증한 뒤 reviewed_cards.json에 기록한다. 가격은 만원 단위. 이미지의 가격 범위는 API 타입별 최고가 범위가 아니라 **해당 동·호수 가격표의 실제 최저~최고**이며, 옵션 포함 여부를 명시한다.

검증 PDF SHA-256, 공식 URL, 검수일, 총세대수 출처, 이미지 출처를 기록한다. API 공고명·물량·접수일이 달라지거나 PDF가 바뀌거나 검수 7일 경과·접수 종료 시 카드를 게시하지 않고 재검수 대기로 보낸다. 규제·대출·자격을 다른 공고에서 복사하거나 추정하지 않는다.

매일 기존 Actions 수집 후 후보의 84㎡ 타입별 최고 공급금액을 조회해 sharecards.json에 검토 대기를 표시한다. 총규모 불명 후보도 검토 대기에 포함한다. 신규 후보는 AI가 공식 공고를 확인해 편집 원본을 추가하면 CI가 PNG/ZIP을 생성한다. 조건을 충족하는 공고가 없으면 이미지를 만들어 채우지 않는다.

카드 이미지 1080×1440 PNG. 단지 전체/이번 모집을 분리, 입지·조건·가격·일정·원문 근거·계정명 표기. 공식 CG가 있으면 출처와 차이 가능성 표시. AI 이미지는 특정 단지의 실제 외관처럼 쓰지 않고 AI 컨셉 표시를 강제한다. 정보 텍스트는 Pillow로 조판해 숫자 오탈자를 방지한다.

카드 디자인: GitHub URL·공식공고/사업주체 출처 문구는 이미지에 표시하지 않는다. 출처는 웹과 편집원본에 유지. 하단은 @woodeok.apt 한 줄만 가운데 정렬한다. QR, 화살표, 인스타 유도문구, 후킹 CTA는 넣지 않는다. 가격·조건·일정은 큰 글자·높은 대비·넓은 여백으로 조판한다.
